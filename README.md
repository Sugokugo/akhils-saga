# Akhil's Saga — Portfolio Website

This is a simple, editable static website built with HTML, CSS and JavaScript. No coding framework or build step is required.

## Files
- `index.html` — page content and sections
- `style.css` — colors, layout, responsive design and animations
- `script.js` — mobile menu, footer year and scroll reveal effects

## Preview on your computer
1. Download and unzip `akhils-saga-website.zip`.
2. Open the `akhils-saga` folder.
3. Double-click `index.html` to open it in your web browser.
4. To edit the site, open the files in a text editor such as Visual Studio Code.

## Personalize it before publishing
Open `index.html` and search for:
- `YOUR_EMAIL@example.com` — replace with your email address.
- `https://www.linkedin.com/in/YOUR-LINKEDIN/` — replace with your LinkedIn profile URL.
- `Project One`, `Project Two`, etc. — replace with your real projects and descriptions.
- `Your Degree / Qualification` — replace with your education details.
- The About Me paragraphs and Skills descriptions — replace with your own story and strengths.

You can change colors near the top of `style.css`, in the `:root` section.

## Publish it online with GitHub Pages
1. Create or sign in to a GitHub account at https://github.com/.
2. Create a new public repository, for example `akhils-saga`.
3. Upload `index.html`, `style.css` and `script.js` (the files inside this folder, not the ZIP).
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then save.
7. GitHub will provide a public website address after deployment. It may take a few minutes.

You can also deploy the folder using https://vercel.com/ or https://www.netlify.com/.

## Important
The project cards, skills, education and contact details currently contain sample placeholder text. Replace those with accurate details before sharing your portfolio.
